Mini panel pogodowy i lista zadań

 Jak uruchomić:
1. `cd tydzien-3-4-react`
2. `npm install`
3. `npm run dev`
4. Otwórz `http://localhost:5173`

 Co robi aplikacja:
1. Po wejściu pobiera aktualną temperaturę z Open-Meteo API
2. Wyświetla losowe państwo z flagą i stolicą z REST Countries API
3. Licznik kliknięć z przyciskami Dodaj i Reset
4. Formularz do dodawania zadań z walidacją (min. 3 znaki)
5. Zadania zapisują się w localStorage i przeżywają odświeżenie
